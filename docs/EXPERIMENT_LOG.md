# 实验记录

## 2026-09-06：M0-M1 CPU 基线

### 环境

- Windows，本机 CPU；
- Python 3.11.9；
- 不使用外部模型 API；
- 自建 5 条商品冒烟数据和 4 条端到端评测数据。

### 方法

- 文本：中文单字与英文/数字词项匹配，并使用平滑 IDF；
- 图片：RGB 分通道直方图和平均亮度；
- 融合：同时有图文时文本 0.65、图片 0.35；
- 排序后调用库存工具，过滤无库存结果。

### 结果

- 自动化测试：6 passed；
- 该结果只验证工程闭环，不代表真实多模态语义能力；
- 下一阶段用固定评测集对比中文 CLIP 与该基线。

### 已知局限

- 中文单字检索不能处理语义相似表达；
- 颜色直方图不理解商品类别、款式和局部结构；
- 当前 Planner 仅覆盖检索与对比两类意图；
- 示例集规模很小，不能作为简历最终指标。
