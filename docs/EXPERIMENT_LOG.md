# 实验记录

## 2026-09-06：M0-M1 CPU 基线

### 环境

- Windows，本机 CPU；
- Python 3.11.9；
- 不使用外部模型 API；
- 自建 5 条商品冒烟数据和 4 条端到端评测数据。

### 方法

- 文本：中文单字与英文/数字词项匹配，并使用平滑 IDF；
- 图片：RGB 分通道直方图和平均亮度；
- 融合：同时有图文时文本 0.65、图片 0.35；
- 排序后调用库存工具，过滤无库存结果。

### 结果

- 自动化测试：6 passed；
- 该结果只验证工程闭环，不代表真实多模态语义能力；
- 下一阶段用固定评测集对比中文 CLIP 与该基线。

### 已知局限

- 中文单字检索不能处理语义相似表达；
- 颜色直方图不理解商品类别、款式和局部结构；
- 当前 Planner 仅覆盖检索与对比两类意图；
- 示例集规模很小，不能作为简历最终指标。

## 2026-09-06：图片上传接口

- 新增 `multipart/form-data` 图片输入；
- 仅允许 JPEG、PNG、WebP，大小不超过 5 MB；
- 对图片内容执行解码校验，并在请求结束后删除临时文件；
- JSON API 禁止传入服务器本地图片路径，避免任意文件读取风险。

## 2026-09-06：中文 CLIP 可切换后端

- 新增共享图文向量空间的编码器协议；
- 接入 `OFA-Sys/chinese-clip-vit-base-patch16` 适配器；
- 商品图文向量与查询图文向量均进行 L2 归一化；
- 用假编码器测试跨模态排序逻辑，CI 不下载大模型；
- 默认仍运行 CPU 轻量基线，CLIP 作为可选依赖启用。

## 2026-09-06：持久化向量索引

- 新增离线商品图文编码与 `vectors.npy` 持久化；
- 索引清单记录目录哈希、编码模型、商品数、向量维度和 UTC 时间；
- 服务可加载已有索引，避免启动时重复编码商品库；
- 目录变化、模型不一致或向量形状异常时拒绝加载。

## 2026-09-06：数据准备管线

- 支持导入 JSONL 和 CSV 商品表；
- 强制记录数据来源与许可证；
- 校验 JPEG、PNG、WebP 图片并按 SHA-256 去重；
- 基于商品 ID 哈希稳定划分 train/validation/test；
- 原始大数据、处理后数据与图片默认不进入 Git。

## 2026-09-06：ABO 数据适配器

- 选择官方 CC BY 4.0 的 Amazon Berkeley Objects 作为真实图文检索数据；
- 只使用约 83 MB 商品 metadata 和约 3 GB 的 256px 图片包；
- 优先提取中文字段，缺失时回退英文；
- 关联主图并映射品牌、颜色、材质、风格等属性；
- 明确 ABO 不用于价格和实时库存评测。

## 2026-09-06：ABO 真实数据冒烟运行

- 下载 `listings_0.json.gz` 与完整图片 metadata，而非下载 3 GB 图片归档；
- 按清单并发下载 100 张 256px 官方商品小图：成功 100，失败 0；
- 转换商品 100 条，缺图 0，缺标题 0，重复图片 0；
- 稳定切分：train 70、validation 18、test 12；
- 本次仅验证端到端数据链路，最终实验扩容到至少 1000 条后再报告模型指标。

## 2026-09-06：中文 CLIP 下载检查

- 复用本机已有 `torch 2.10.0+cpu` 与 `transformers 4.57.3`；
- 权重约 753 MB，但当前 Hugging Face 通道长时间保持 0%，未完成下载；
- 暂不把网络失败当作模型实验结果，后续在 AutoDL 或稳定模型源恢复；
- 先实现统一 Recall@K 与 MRR 评测器，保证模型替换前后协议一致。

### CPU 基线 sanity check

在12条 test 商品上运行标题检索自身与原图检索自身，两者 Recall@1/5/10 和 MRR 均为 1.0。该测试只能证明目录、图片路径、排序与指标计算链路一致，不能证明语义泛化能力，不作为简历最终指标。正式评测将使用改写文本和不同视角图片，避免查询与库内容完全相同。

## 2026-09-06：属性需求困难集 v0

从 test 商品的类别、颜色、材质和风格等字段生成12条自然语言购物需求，查询中不复制商品标题。CPU 词项基线结果：

| 指标 | 结果 |
| --- | ---: |
| Recall@1 | 0.3333 |
| Recall@5 | 0.7500 |
| Recall@10 | 0.8333 |
| MRR | 0.5139 |

该版本仍是规则生成的小规模评测集，后续需要人工复核并加入同义改写、类目歧义和不同视角图片查询。它用于模型迭代对比，不作为最终公开结论。
