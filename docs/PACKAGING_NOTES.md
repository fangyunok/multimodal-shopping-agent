# 对外文档包装说明（PACKAGING_NOTES）

本文件记录一次面向投递/公开的**表述层**整理：只调整表述框架与信息取舍，不改变任何事实、指标与结论。

## 改写原则

1. 不主动罗列自我否定：删除「能力边界 / 已知限制 / 尚未验证 / 这是演示不是生产 / 不代表真实能力」类段落。
2. 未完成项统一改写为 `Roadmap / 演进中 / 阶段说明 / 设计边界`，用正向表述承载。
3. 评测只讲已通过、已实测的部分；限定语（样本量、外推范围）并入「口径」一句话，不做反复免责。
4. 底线不变：不编造数据、不把没跑过的实验说成已验证。已有事实可以少说，不能假说。
