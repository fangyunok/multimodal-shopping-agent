# 系统架构

```text
用户文字 / 商品图片
        |
        v
请求解析与约束抽取
        |
        v
Agent Planner ---------> 工具注册表
        |                    |-- search_products
        |                    |-- check_inventory
        |                    `-- compare_products
        v
混合检索器
  |-- 文本编码器
  |-- 图片编码器
  |-- 向量索引
  `-- 过滤与重排
        |
        v
基于证据生成回答 + 可审计 tool trace
        |
        v
离线评测：检索 / 工具 / 约束 / 端到端
```

当前版本的 Planner 是确定性基线，文本检索采用轻量词项匹配，图片检索采用颜色直方图。它们用于验证数据流、工具协议和评测代码。后续替换为中文 CLIP 与视觉语言模型时，API 数据模型和评测接口保持稳定。

## 关键设计决定

1. 先做无 API、无 GPU 的闭环，确保仓库可复现。
2. 价格、库存和对比属于确定性工具，模型只负责规划与解释。
3. 保存工具轨迹，使错误可以归因到检索、参数或生成环节。
4. 多模态能力必须通过跨模态检索指标证明，而不是仅凭演示截图。
5. 向量索引清单绑定目录哈希与模型名，避免加载过期或不兼容向量。
